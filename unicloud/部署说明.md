# 建工青协官网 uniCloud 免费后端部署说明

## 1. 服务空间

使用你的服务空间：

```text
mp-53d28a73-8fcd-4a91-a0c1-16249a142f32
```

建议使用阿里云免费空间。免费空间到期前要在 uniCloud 控制台手动续期。

## 2. 创建数据库集合

在 uniCloud 控制台创建 6 个集合：

```text
applications
messages
activities
site_stats
site_settings
admin_users
```

然后导入这些文件：

```text
activities     -> unicloud/import/activities.json
site_stats     -> unicloud/import/site_stats.json
site_settings  -> unicloud/import/site_settings.json
admin_users    -> unicloud/import/admin_users.json
applications   -> unicloud/import/applications.json
messages       -> unicloud/import/messages.json
```

默认后台账号示例：

```text
email: admin@gyzy.org
password: ChangeMe123!
```

导入后请尽快修改邮箱和密码。

## 3. 上传云函数

用 HBuilderX 打开：

```text
C:\Users\ccc\gyzy-pages
```

然后：

1. 绑定服务空间 `mp-53d28a73-8fcd-4a91-a0c1-16249a142f32`。
2. 右键 `unicloud/cloudfunctions/gyzy-api`。
3. 选择上传部署。
4. 在 uniCloud 控制台给 `gyzy-api` 开启 URL 化。
5. URL 路径填：

```text
/gyzy-api
```

6. 复制生成的完整 HTTP 地址。

## 4. 配置安全域名

因为网站在 GitHub Pages，必须在 uniCloud 控制台给 Web 跨域安全域名添加：

```text
chenxuanzai107-dev.github.io
```

本地测试可以再加：

```text
127.0.0.1:*
localhost:*
```

端口也算跨域配置的一部分，所以本地建议用 `:*`。

## 5. 填写 API 地址

打开：

```text
js/backend-config.js
```

把 `apiUrl` 改成刚复制的完整地址：

```js
apiUrl: 'https://你的uniCloud云函数地址/gyzy-api'
```

改完后提交并推送到 GitHub Pages。

## 6. 验收

1. 首页能显示活动和统计。
2. 前台能提交报名。
3. 前台能提交留言。
4. `login.html` 能登录后台。
5. 后台能查看报名、留言、活动。
6. 后台能新增、修改、删除活动。

第一版为了免费和稳定，暂时不启用图片上传。活动封面和首页 Banner 先用外部图片 URL 或默认图片。
