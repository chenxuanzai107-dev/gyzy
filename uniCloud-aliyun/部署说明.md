# 建工青协官网 uniCloud 免费后端部署说明

## 1. 当前服务空间

使用这个阿里云免费空间：

```text
mp-53d28a73-8fcd-4a91-a0c1-16249a142f32
```

免费空间到期前需要在 uniCloud 控制台手动续期。

## 2. 数据库

数据库结构和初始化数据已经放在：

```text
uniCloud-aliyun/database/
```

包含 6 个集合：

```text
applications
messages
activities
site_stats
site_settings
admin_users
```

每个集合都有：

```text
集合名.schema.json
集合名.init_data.json
```

本次已经通过 HBuilderX CLI 创建集合并初始化数据。默认后台账号：

```text
email: admin@gyzy.org
password: ChangeMe123!
```

上线后请尽快修改邮箱和密码。

## 3. 云函数

云函数目录：

```text
uniCloud-aliyun/cloudfunctions/gyzy-api
```

本次已经上传到阿里云空间 `jgqx`。如果以后要重新上传，在 HBuilderX 中右键 `gyzy-api` 选择上传部署即可。

## 4. URL 化

还需要在 uniCloud Web 控制台为 `gyzy-api` 开启 URL 化。

建议路径：

```text
/gyzy-api
```

开启后复制完整 HTTPS 地址。地址拿到后，把它填到：

```text
js/backend-config.js
```

示例：

```js
apiUrl: 'https://你的uniCloud云函数地址/gyzy-api'
```

## 5. Web 安全域名

因为前端部署在 GitHub Pages，需要在 uniCloud 控制台添加安全域名：

```text
chenxuanzai107-dev.github.io
```

本地测试可再添加：

```text
127.0.0.1:*
localhost:*
```

## 6. 验收

1. 首页能显示活动和统计。
2. 前台能提交报名。
3. 前台能提交留言。
4. `login.html` 能登录后台。
5. 后台能查看报名、留言、活动。
6. 后台能新增、修改、删除活动。

图片上传已启用，后台管理员可以上传首页 Banner 和活动封面。为了控制免费额度，单张图片限制为 2MB，上传后的图片会占用 uniCloud 云存储和 CDN 流量额度。外部图片 URL 仍然可以继续使用。
